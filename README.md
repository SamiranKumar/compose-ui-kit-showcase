# Compose UI Kit Showcase

A modern Android project built using Jetpack Compose, focused on creating reusable UI components and a scalable design system.

---

## Overview

Compose UI Kit Showcase is a structured collection of UI components built with Jetpack Compose.  
The project follows a clean architecture approach and demonstrates how to design and organize reusable UI elements for Android applications.

---

## Features

- Reusable UI components (Buttons, Inputs, Cards, etc.)
- Centralized design system (Color, Typography, Shapes)
- Clean and modular project structure
- Utility extensions and helper classes
- Material 3 design implementation

---

## Tech Stack

- Kotlin
- Jetpack Compose
- Material 3

## Commit Message Convention

| Type       | Meaning                               |
|------------|--------------------------------------|
| feat       | New feature                          |
| fix        | Bug fix                              |
| chore      | Maintenance / setup                  |
| refactor   | Code improvement                     |
| docs       | Documentation                        |
| style      | Formatting                           |
| test       | Add/update tests                     |

### Example


feat(button): add primary button component
fix(input): handle null input state
chore(deps): update dependencies
